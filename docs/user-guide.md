# Руководство пользователя — Ценовой аналитик

Это руководство для ценового аналитика — основного пользователя системы, который принимает решения по ценам на основе рекомендаций системы.

## Как просмотреть и утвердить ценовую рекомендацию

1. Войдите в систему, указав логин и пароль.
2. Откройте раздел «Ценовые рекомендации».
3. Выберите нужный товар из списка.
4. Изучите рекомендуемую цену и факторы, которые на неё повлияли.
5. Нажмите «Утвердить», если согласны с рекомендацией, либо измените цену вручную и сохраните, либо нажмите «Отклонить».
6. Дождитесь сообщения о сохранении решения.

## Как запустить A/B-тестирование стратегий ценообразования

1. Откройте раздел «A/B-тестирование».
2. Выберите товарную категорию, которую хотите протестировать.
3. Выберите две стратегии ценообразования для сравнения.
4. Нажмите «Запустить тест».
5. Дождитесь сообщения о запуске эксперимента.
6. По окончании периода тестирования откройте раздел результатов, чтобы увидеть, какая стратегия оказалась эффективнее.

## Возможные проблемы

| Что вы видите | Что делать |
|---|---|
| «Неверный логин или пароль» | Проверьте правильность ввода. После 5 неудачных попыток подряд учётная запись будет временно заблокирована — обратитесь к администратору |
| Нужная рекомендация отсутствует в списке | Рекомендации формируются по расписанию; если прошло меньше суток с последнего расчёта, подождите или обратитесь к администратору |
| После утверждения или отклонения статус рекомендации не обновился | Обновите страницу; если проблема повторяется — сообщите администратору |
| Результаты A/B-теста ещё не отображаются | Эксперимент продолжается; результаты доступны только после завершения выбранного периода тестирования |
