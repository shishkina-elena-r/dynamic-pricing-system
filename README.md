# Dynamic Pricing System

Информационная система динамического ценообразования для розничной торговли и e-commerce: на основе моделей машинного обучения прогнозирует спрос и формирует рекомендации по оптимальной цене для каждого товара с учётом бизнес-ограничений (минимальная маржа, ценовой коридор, РРЦ). Проект разрабатывался в рамках дисциплины «Программная инженерия».

## Материалы проекта

В папке [`docs`](docs) собраны материалы, подготовленные в прошлом семестре:

- `Требования.docx` — функциональные и нефункциональные требования
- `Сценарии.docx` — пользовательские сценарии и модель жизненного цикла
- `Архитектура.docx` — архитектура системы
- `Диаграммы.docx` — UML-диаграммы (классов и последовательности)
- `Тест-кейсы.docx` — тест-кейсы
- `ПЗ_Шишкина_ЗБ-АД-23 (прошлый семестр).docx` — полная пояснительная записка прошлого семестра
