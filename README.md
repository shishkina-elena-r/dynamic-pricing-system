# Dynamic Pricing System

Информационная система динамического ценообразования для розничной торговли и e-commerce: на основе моделей машинного обучения прогнозирует спрос и формирует рекомендации по оптимальной цене для каждого товара с учётом бизнес-ограничений (минимальная маржа, ценовой коридор, РРЦ). Проект разрабатывался в рамках дисциплины «Программная инженерия».

## Пользователи

- **Ценовой аналитик** — основной пользователь: просматривает рекомендации, утверждает, корректирует или отклоняет их, запускает A/B-тестирование
- **Администратор** — управляет пользователями и ролями, настраивает интеграции, управляет версиями ML-моделей, просматривает журнал аудита
- **Наблюдатель (руководитель)** — просматривает сводные отчёты и динамику цен, получает уведомления о значимых изменениях

## Основные возможности

- Прогнозирование спроса на товары на основе моделей машинного обучения
- Расчёт рекомендуемой цены с учётом прогноза спроса и бизнес-ограничений (минимальная маржа, ценовой коридор, РРЦ)
- Утверждение, корректировка и отклонение ценовых рекомендаций ценовым аналитиком
- A/B-тестирование различных стратегий ценообразования
- Отчётность и аналитические дашборды по эффективности ценообразования
